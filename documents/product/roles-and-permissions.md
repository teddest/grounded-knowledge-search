# Workspace Owner

The Workspace Owner manages billing, can change subscription settings, can assign administrators, and can start workspace exports. There is one primary owner per workspace.

# Workspace Administrator

A Workspace Administrator can manage workspace configuration, assign members, and start exports. Administrators cannot change the billing owner unless the owner completes the transfer process.

# Member

Members can use the workflows assigned to them and can view records allowed by workspace configuration. Members cannot manage billing, change roles, or start workspace exports.

# Viewer

Viewers have read-only access to permitted records. Viewers cannot modify records, manage workspace configuration, or start exports.

# Support access

Support agents do not receive standing access to customer workspaces. If troubleshooting requires access, the customer must grant temporary administrator access through the approved support process. Support access is recorded in the audit log and should be removed when troubleshooting is complete.
